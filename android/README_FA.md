# اپ اندروید ختم جمعی

اپ بومی اندروید برای همراهی با وب‌سایت «ختم جمعی» است. اپ و سایت از یک API و آمار مشترک استفاده می‌کنند؛ ختم قرآن بخش پیش‌فرض است و ختم صلوات نیز در همان صفحه در دسترس قرار دارد.

## امکانات

- انتخاب نیت و مشاهدهٔ پیشرفت زندهٔ هر نیت
- رزرو آیه، نمایش متن عربی و ترجمهٔ فارسی، پخش صوت و ثبت انجام آیه
- شمارندهٔ لمسی صلوات با میان‌برهای ۱، ۱۴، ۱۰۰، ۳۱۳ و ۱۰۰۰ و مقدار دلخواه
- ادامهٔ رزرو فعال پس از بستن اپ و نمایش زمان باقی‌مانده
- ذخیرهٔ آخرین وضعیت برای نمایش آفلاین و همگام‌سازی خودکار پس از اتصال
- اشتراک‌گذاری دعوت، حالت روشن/تیره، راست‌به‌چپ کامل و اعداد فارسی
- پنل مدیریت نیت‌ها برای افزودن، ویرایش و بایگانی؛ رمز مدیر داخل اپ ذخیره یا در سورس قرار داده نمی‌شود

## اجرا و ساخت

پیش‌نیازها: JDK 17، Android SDK 37 و Android Studio سازگار با AGP 9.3.

```bash
cd android
./gradlew testDebugUnitTest lintDebug assembleDebug
```

فایل نصب آزمایشی در مسیر زیر ساخته می‌شود:

```text
app/build/outputs/apk/debug/app-debug.apk
```

آدرس سرویس در `KhatmRepository.BASE_URL` تعریف شده است:

```text
https://khatm.imangpt1996.chatgpt.site
```

## ساختار

- `data/`: مدل‌ها، تبدیل JSON، ارتباط شبکه، نشست و کش محلی
- `ui/`: ViewModel و رابط Compose
- `ui/theme/`: رنگ‌ها، تایپوگرافی و حالت روشن/تیره
- `res/`: آیکن تطبیقی، تم سیستم و تنظیمات امنیت شبکه

این پروژه هیچ کلید خصوصی یا رمز مدیریتی را در APK قرار نمی‌دهد. برای انتشار در فروشگاه، یک کلید امضای release را فقط در محیط امن CI یا Play App Signing نگه‌داری کنید.
