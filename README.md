# Khatm — ختم گروهی قرآن

وب‌اپ فارسی، موبایل‌اول و بدون ثبت‌نام برای ختم جمعی قرآن. هر بازدیدکننده یک آیه آزاد می‌گیرد، متن عربی + ترجمه فارسی + صوت همان آیه را می‌بیند و با زدن «خواندم» سهم خود را ثبت می‌کند. آیات دقیقاً از ابتدای قرآن به‌ترتیب پیش می‌روند و ختم فقط زمانی کامل می‌شود که هر ۶۲۳۶ آیه ثبت شده باشند.

## تجربه کاربر

- ورود بدون ساخت حساب
- تخصیص خودکار یک آیه از ختم جاری
- متن عربی، ترجمه فارسی و تلاوت آیه‌به‌آیه
- دکمه واضح «خواندم» و امکان گرفتن آیه بعدی
- نمایش زمان باقی‌مانده رزرو آیه
- حفظ همان آیه بعد از refresh در همان مرورگر
- بازگرداندن سهم منقضی به صف تا هیچ آیه‌ای جا نماند
- شمارنده زنده پیشرفت، ختم‌های کامل و افراد در حال خواندن
- اشتراک‌گذاری سریع لینک برای دوستان
- تغییر ساده نیت با رمز مدیریت
- RTL، موبایل‌اول، reduced-motion و حالت آفلاین/خطای شبکه

## معماری و تضمین ترتیب

- **Next.js 16.3.3** برای رابط و Route Handlerهای سرور
- **PostgreSQL** به‌عنوان منبع حقیقت صف، رزروها و تاریخچه ختم
- تراکنش و `FOR UPDATE` برای جلوگیری از race condition
- **Al Quran Cloud** برای متن قرآن و ترجمه
- **Islamic Network CDN** برای صوت آیه‌به‌آیه

تخصیص آیه صرفاً روی سرور انجام می‌شود. هر چرخه شامل شماره‌های سراسری `1..6236` است و سامانه کوچک‌ترین آیه‌ای را انتخاب می‌کند که نه خوانده شده و نه رزرو فعال دارد. بنابراین حتی با چند کاربر هم‌زمان، آیه‌ها بدون تداخل و با حفظ ترتیب جمعی تخصیص داده می‌شوند.

## منطق رزرو

- هر session ناشناس فقط یک سهم فعال در چرخه جاری دارد.
- مهلت پیش‌فرض ۴۵ دقیقه است و با `CLAIM_TTL_MINUTES` تنظیم می‌شود.
- سرور مقدار را به بازه ۱۰ تا ۱۸۰ دقیقه محدود می‌کند.
- انقضا هم هنگام تخصیص بعدی و هم هنگام ثبت «خواندم» بررسی می‌شود؛ آیه منقضی‌شده قابل ثبت نیست و دوباره به صف برمی‌گردد.
- refresh همان سهم فعال را برمی‌گرداند.

## تکمیل ختم

ختم با خوانده‌شدن صرفاً «آخرین شماره آیه» تمام نمی‌شود. پس از هر ثبت، تعداد رکوردهای تکمیل‌شده چرخه بررسی می‌شود و فقط در صورت رسیدن به **۶۲۳۶**:

1. چرخه در `khatm_history` ثبت می‌شود.
2. `completed_khatms` یک واحد زیاد می‌شود.
3. `current_cycle` یک واحد زیاد می‌شود.
4. ختم جدید از آیه ۱ آغاز می‌شود.

## راه‌اندازی با Docker Compose

```bash
cp .env.example .env
```

سپس حتماً در `.env` دو مقدار زیر را با secretهای تصادفی قوی عوض کنید:

- `POSTGRES_PASSWORD`
- `ADMIN_TOKEN`

بعد:

```bash
docker compose up -d --build
```

سایت: `http://localhost:3000`

Health check: `http://localhost:3000/api/health`

Docker image در شروع، schema دیتابیس را به‌صورت idempotent اجرا می‌کند و سپس برنامه را بالا می‌آورد.

## اجرای توسعه‌ای

Node.js 22 تا 24 و PostgreSQL لازم است.

```bash
npm install
cp .env.example .env
npm run db:init
npm run dev
```

## متغیرهای مهم محیطی

| Variable | کاربرد |
| --- | --- |
| `DATABASE_URL` | اتصال PostgreSQL |
| `DATABASE_SSL` | برای DBهای managed که SSL می‌خواهند |
| `ADMIN_TOKEN` | رمز تغییر نیت؛ حداقل ۲۰ کاراکتر و غیر placeholder |
| `CLAIM_TTL_MINUTES` | مهلت رزرو هر سهم |
| `QURAN_API_BASE` | API محتوای قرآن |
| `QURAN_ARABIC_EDITION` | edition متن عربی |
| `QURAN_PERSIAN_EDITION` | edition ترجمه فارسی |
| `QURAN_AUDIO_EDITION` | قاری صوت |
| `QURAN_AUDIO_BITRATE` | bitrate صوت |

## تغییر نیت

آیکن تنظیمات بالای صفحه را بزنید، نیت جدید و `ADMIN_TOKEN` را وارد کنید. تغییر نیت، پیشرفت ختم جاری را صفر نمی‌کند.

## امنیت و حریم خصوصی

- نام، شماره تلفن یا حساب کاربری از خوانندگان گرفته نمی‌شود.
- شناسه ناشناس session در cookie `HttpOnly` نگه‌داری می‌شود.
- mutationهای مرورگر در برابر درخواست cross-site بررسی می‌شوند.
- رمز مدیریت با مقایسه زمان‌ثابت بررسی می‌شود.
- Docker Compose با secret پیش‌فرض شناخته‌شده بالا نمی‌آید.
- اطلاعات حساس در repository قرار ندهید؛ `.env` در `.gitignore` است.
- برای اینترنت عمومی، rate limiting در reverse proxy/Coolify و backup منظم PostgreSQL توصیه می‌شود.

## CI

GitHub Actions در هر push/PR این مراحل را اجرا می‌کند:

1. `npm install`
2. `npm run typecheck`
3. `npm run build`
4. راه‌اندازی PostgreSQL واقعی
5. اجرای schema
6. اجرای Quran API mock قطعی و محلی
7. اجرای برنامه production
8. smoke test API شامل:
   - health
   - تخصیص آیه ۱
   - حفظ همان claim با session یکسان
   - ثبت موفق
   - حرکت به آیه ۲
   - رد کردن ثبت بعد از انقضای رزرو
   - بازگشت آیه منقضی به صف
   - رد/قبول رمز مدیریت
   - رد mutation با Origin بیگانه
   - ۲۰ claim هم‌زمان و اثبات یکتایی و ترتیب `1..20`

## داده قرآن

پیش‌فرض‌ها:

- عربی: `quran-uthmani-quran-academy`
- فارسی: `fa.makarem`
- صوت: `ar.alafasy`، bitrate 128

سایت متن ترجمه را بازنویسی نمی‌کند و داده runtime را از provider نمایش می‌دهد. قبل از تغییر provider/edition، شرایط استفاده و مجوز همان منبع را بررسی کنید.
