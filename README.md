# ختم جمعی قرآن و صلوات

وب‌اپ فارسی، راست‌چین و موبایل‌اول برای همراهی جمعی در ختم قرآن و ختم صلوات. ختم قرآن، حالت پیش‌فرض سایت است.

## امکانات اصلی

- تخصیص ترتیبی و بدون تداخل یک آیه از ختم جاری
- متن عربی، ترجمه فارسی، صوت آیه و زمان رزرو سهم
- ثبت «خواندم»، دریافت آیه بعدی و شروع خودکار ختم تازه پس از ۶۲۳۶ آیه
- ختم صلوات با تعدادهای آماده و تعداد دلخواه
- شمارنده مستقل ختم قرآن و صلوات برای هر نیت
- سه نیت اولیه:
  - برای سلامتی و تعجیل در فرج امام زمان (عج)
  - به نیت مرحوم محمدعلی رامش
  - به نیت چهارده معصوم (ع)
- پنل مدیریت رمزدار برای افزودن، ویرایش و حذف نیت از فهرست عمومی
- اشتراک‌گذاری، نمایش وضعیت اتصال، خطاهای قابل‌بازیابی و رابط دسترس‌پذیر
- بدون ثبت‌نام و بدون دریافت نام یا شماره تلفن کاربران

## معماری

- `Vinext` و `React`
- `Cloudflare D1` برای نگه‌داری پایدار نیت‌ها، سهم‌های قرآن و شمارنده‌ها
- `Drizzle` برای schema و migration
- `Al Quran Cloud` برای متن عربی و ترجمه فارسی
- `Islamic Network CDN` برای صوت آیه‌به‌آیه

فایل migration در مسیر `drizzle/` قرار دارد و هنگام انتشار اعمال می‌شود. سه نیت اولیه به‌صورت idempotent در نخستین درخواست برنامه ثبت می‌شوند.

## تنظیم ضروری

متغیر محرمانه زیر باید در محیط انتشار تنظیم شود:

```text
ADMIN_TOKEN=<a strong password of at least 20 characters>
```

رمز در کد یا repository ذخیره نمی‌شود.

## توسعه محلی

```bash
npm ci
npm run dev
```

برای lint:

```bash
npm run lint
```

برای ساخت migration پس از تغییر schema:

```bash
npm run db:generate
```

## حریم خصوصی و امنیت

- شناسه ناشناس هر مرورگر فقط در cookie از نوع `HttpOnly` نگه‌داری می‌شود.
- درخواست‌های تغییردهنده از مبدأهای بیگانه رد می‌شوند.
- رمز مدیریت به‌صورت secret محیطی نگه‌داری و با مقایسه ثابت‌زمان بررسی می‌شود.
- حذف نیت، soft delete است؛ سابقه و شمارنده‌های قبلی از بین نمی‌رود.
